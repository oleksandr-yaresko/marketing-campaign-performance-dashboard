# Marketing Campaign Performance Dashboard

## Project Overview

This project analyzes marketing campaign performance using SQL, PostgreSQL, and Power BI.

The goal was to evaluate campaign effectiveness across marketing channels, customer segments, locations, and campaign types to support data-driven marketing decisions.

---

## Business Problem

Marketing teams need visibility into:

- Which channels generate the highest ROI
- Which customer segments convert best
- Which locations perform strongest
- Which campaign types deliver the best engagement

This dashboard provides actionable insights for marketing optimization and budget allocation.

## Key Findings

- Average ROI: 5.0x
- Average Conversion Rate: 8.01%
- Average CTR: 9.98%
- Influencer campaigns achieved the strongest conversion performance.
- Social Media campaigns delivered the highest CTR.
- Marketing performance remained highly consistent across customer segments and locations.
