# Marketing Campaign Performance Dashboard

## Project Overview

This project analyzes marketing campaign performance using PostgreSQL, SQL, and Power BI.

The objective was to evaluate marketing effectiveness across channels, customer segments, locations, and campaign types while building an end-to-end analytics workflow from data preparation to dashboard development.

---

## Tools Used

* PostgreSQL
* SQL
* Power BI
* Data Modeling
* Data Visualization

---

## Business Questions

* Which marketing channels generate the best performance?
* Which customer segments convert most effectively?
* Which locations show the strongest results?
* Which campaign types achieve the highest conversion rates and CTR?
* How does campaign performance change over time?

---

## Key KPIs

* Total Campaigns: 200,000
* Total Clicks: 110 Million
* Average ROI: 5.0x
* Average Conversion Rate: 8.01%
* Average CTR: 9.98%
* Average Campaign Duration: 37.5 Days
